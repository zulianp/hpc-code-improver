# /hpc — improve this repository

Usage: `/hpc [area] [path]`

Area is `performance`, `portability`, `api`, `testing`, `regression`, `ci`, or `all` (default `all`). An optional path limits the audit.

Follow `.cursor/skills/hpc-improver/SKILL.md`.

The user picks which findings to address, and approves or rejects each finished branch. Do the proposal, the implementation, the gate, and the adversarial review in this chat. Do not ask them to run another command or open another chat. A performance finding is shown on a canvas, base against candidate, before the approval question.
